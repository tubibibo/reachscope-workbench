安全响应头缺失（missing-headers）

这个页面在 baseline 与 hardened 两个剖面下内容完全相同，状态码都是 200。两个剖面的差异全部在 HTTP 响应头上：baseline 几乎不带安全响应头，hardened 带上了四个最常见的。

响应头作用（一句话）
X-Content-Type-Options: nosniff禁止浏览器猜测（嗅探）响应的真实类型，降低把普通文本当脚本或样式执行的风险。
X-Frame-Options: DENY禁止本页面被其他站点用 iframe 嵌套，缓解点击劫持。
Referrer-Policy: no-referrer从本页面跳转到其他站点时不发送 Referer，避免把完整 URL 泄露给第三方。
Content-Security-Policy: default-src 'none'默认禁止加载任何资源，是最收紧的内容安全策略起点。

本场景要看的是响应头，不是页面内容：请在证据面板或浏览器开发者工具的网络面板里查看响应头。页面内容两个剖面一模一样，这是刻意设计的——差异只允许来自配置。

先在 baseline 剖面访问一次并记录响应头，再切换到 hardened 剖面访问同一条 URL，逐行对比。
