# ADR 0005：受控教学来源与请求契约

- 日期：2026-11-01
- 状态：Accepted for local workbench 0.11

## 背景

新用户需要亲手复现检查与整改，不应靠静态数字或商业模型解释全部结果。
受管教学网站的真实 HTTP 响应也不能混成生产目标安全结论。手写 TypeScript 类型
与 Python API 会漂移，且类型缩小不等于运行时对象字段被删除。

## 决策

固定教学站点是入站应用组装的 loopback 集成适配器，按显式操作启动/切配置/停止，
不动态加载代码、不自动发检查或模型请求。普通资产、检查、证据、案例和复测用例
仍是事实来源。核心不导入 Lab 集成，也不因模型或示例而改变关闭规则。

schema 6 为资产加可空服务端 provenance，任务关联快照保留它。来源仅在当前精确
受管网址的资产登记时确认，不放进客户提交字段或分析配置，不改变幂等请求指纹。
重放取原记录。旧数据维持 NULL，不根据地址/标题补造登记。采集到的版本头是
独立响应事实，不作远程认证；站点停掉后历史仍不可变，服务不自动复活旧地址。

保存的 Web 检查可在没有 AI 时读取已执行且有证据的控制指南。Nginx 片段由用户
明确选择，并保留适用前提/回滚/复测，既不自动识别技术栈也不部署或执行命令。
模型仍只能选择既有控制/证据 ID；连通、带凭据目录 GET 和付费推理分开授权。

用实际 OpenAPI 和锁定 openapi-typescript 生成请求类型，默认门禁验证漂移。
保留运行时请求白名单及后端严格校验，不能用 TypeScript 的 Pick 掩盖额外字段。
手写响应模型仍需实际 API/浏览器验证，不宣称生成工具覆盖整个客户端。

## 后果与验证

安装仍只有 Python 和打包前端；Node/生成工具只用于开发。临时 Lab 生命周期、
并发、CAS、额外字段、伪来源、实际采集、升级/重放和关闭清理都有回归。
本机浏览器验证完整闭环，单独 CI job 复用该脚本。无公网目标、商业 API 账号或
自动攻击依赖；Nginx 真实部署和商业模型成功推理仍需另行验收。
