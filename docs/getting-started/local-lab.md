# 本地教学：亲手完成检查与修复

0.11.0，2026-11-01。入口：`http://127.0.0.1:8765/#/lab`。

这是项目管理的固定 HTTP 网站，只监听 `127.0.0.1` 随机端口。它实际产生网络响应，
经过正常资产、检查、证据和案例接口，不用写死的成功结果，也不代表生产目标。
基础闭环不需要 AI 账号。

## 操作顺序

1. **启动本地教学站点**。此时只启动站点，不保存资产、不发检查、不调用模型。
2. **保存教学资产**，选择 HTTP/响应头/页面检查，再明确执行基线检查。
3. 打开基线证据，或在结果的「配置实施指南」读取无需 AI 的人工手册。
4. 读取基线候选，选择实际观察项建立教学验证事项；没有证据不会预造发现。
5. 明确应用固定补强配置，地址不变；此操作不部署 Nginx，也不修改其他网站。
6. 明确执行补强后复测，读取字段比较和案例复测结论。
7. 复测满足条件后填写自己的说明，再人工关闭；比较结果不会自动关闭事项。
8. 停止教学站点。已保存的基线、复测、事项和来源仍保留。

## 实际演示内容

| 项目 | 初始版 | 补强版 |
|---|---|---|
| CSP | 缺少 | 固定、严格的示例策略 |
| MIME 嗅探 | 缺少 nosniff | `X-Content-Type-Options: nosniff` |
| 页面嵌入 | 缺少限制 | CSP frame-ancestors 与 X-Frame-Options |
| 来源策略 | unsafe-url | no-referrer |

固定页面没有脚本、外链、上传、登录或私人数据。HTTP 场景不演示 TLS/HSTS。
响应头变化不证明应用整体安全或漏洞已经被利用；真实业务仍需独立回归。

## 来源与生命周期

资产创建时，只有与**当前受管会话精确网址**匹配的保存网站资产才由服务端登记
`provenance.kind=local_training`、标签和会话 ID。客户端不能提交这个字段。
任务快照保存该来源，重新打开历史、重启或导出不会把它改成生产结果。
旧记录的新字段为 NULL，不根据名字、任意 loopback URL 或响应头补造历史来源。

已采集响应保留固定的 Lab Session/Profile/Generation 头，表明那次实际响应的版本。
这些头不是加密认证，远程网页仿造头也不能让资产获得受管会话登记。
切换配置带版本令牌，过期操作返回冲突；已保存的证据不被改写。

站点本身是临时服务。停止/重启后旧地址可能失效，重新启动会产生新会话；旧历史
可读，但不能把失败请求算成修复。并发请求以实际保存响应为准，不根据按钮名字推断结果。
最多同时处理 8 个连接，连接超时 2 秒，仅提供固定 Host 和 `/` 路径的 GET。

## 接口

- `GET /api/lab`：状态、会话、版本令牌、当前地址、来源、限制和建议资产输入。
- `POST /api/lab/start`：无 body 或 `{}`；重复启动返回当前会话，不重置配置。
- `POST /api/lab/configure`：`{generation,profile:"baseline"|"hardened"}`。
- `POST /api/lab/stop`：无 body 或 `{}`；幂等停止。所有写请求仍需本地客户端和同源校验。

状态读取不启动网站。额外目标、端口、HTML、任意头部和脚本字段均被拒绝。
