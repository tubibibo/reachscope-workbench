# 网络行为清单

本页枚举应用全部可能产生的对外网络行为,供安装前审计。除下列两条路径外,
应用不发起任何其他出站连接:没有遥测、没有更新检查、没有账户服务、
没有第三方统计。

服务端只绑定 `127.0.0.1`(见 `reachscope_workbench/cli.py`),并用
`TrustedHostMiddleware` 拒绝其他 Host 头;工作区数据(SQLite 与上传产物)
保存在本机磁盘。

## 出站路径 1:Web 探测(仅 HTTP 探测模块)

| 项 | 行为 |
|---|---|
| 触发 | 操作者在新建检查第 2 步逐条列出的精确 URL(最多 20 个) |
| 方法 | 有限次 GET,跟随重定向有上限;不爬取、不扫描其他端口、不执行脚本 |
| 目标限制 | 默认拒绝本机/内网/非全局地址;勾选「包含我的本机或内网地址」后才放行(元数据地址无论如何拒绝) |
| 数据量 | 响应正文预算 512 KiB;超限即截断并标记 |
| DNS | 每个目标只解析一次并固定使用首个答案(防 rebinding) |
| 代码 | `reachscope_workbench/modules/web/probe.py`、`modules/web/scope.py` |

## 出站路径 2:AI 研判(默认关闭)

| 项 | 行为 |
|---|---|
| 触发 | 操作者在「AI 接口」页配置服务商并显式开启;每次请求还需单独同意 |
| 目的地 | 操作者自己填写的 OpenAI 兼容端点(预置项仅是配置模板,不含任何密钥) |
| 内容 | 证据编号与控制项候选清单的摘要;不发送原始响应全文 |
| 数据量 | 响应上限 128 KiB;不自动重试;不接受模型返回的工具调用 |
| 代码 | `reachscope_workbench/integrations/ai_provider.py`、`core/ai_contracts.py` |

## 其余模块

Android / 云配置 / 主机防御三个模块完全离线:只解析上传的 APK、
Terraform Plan/IAM JSON 与 SSH/Nginx 配置及日志文件,不产生任何网络请求。
教学实验室(本地教学)仅与本机 127.0.0.1 的临时端口通信。

## 验证方式

以上清单可直接复核:在隔离网络中运行应用并观察其唯一出站行为,或审计
上表列出的源码文件。任何一处与本页不符,请作为 bug 报告。
